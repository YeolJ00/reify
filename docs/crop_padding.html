Pick a framing

The same rendered clip (tilt probe, final parameters) cropped at four paddings plus the uncropped frame. Padding is a fraction of the object's own travel box added on each side, so it scales with how far the object moves. The outlined one is what the pipeline uses now.

One thing the book row shows: it is 74×74 at every padding, because at μ = 0.855 it barely slips, so its travel box collapses to the 72 px floor and padding has nothing to scale. A tight crop and a wide one are the same picture for an object that does not move — which is its own argument for a wider default.

Trade-off

Tighter keeps neighbouring objects out of the frame — measured IoU between adjacent crops was 0.08 at the current setting, and boxes fully contained their neighbour before the fix. Wider gives the judge the table edge and the tilt itself as context, which for a slip-angle question may be exactly what it needs: the incline is the thing being judged against, and a tight crop removes it. Uncropped costs nothing extra to render but means every object in the scene gets the same clip, so the per-object question becomes ambiguous again.
